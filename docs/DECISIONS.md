# 恢复边界补充

手册14.3节审查通过真实进程终止复现：API退出后，原任务会永久保持RUNNING。新增启动恢复将该任务终结为FAILED／SERVER_RESTARTED，重新核对并保留已由UC发布的持久化快照，不自动续算。单运行目录只允许一个API实例；清理孤儿角色先核对运行上下文，再使用Linux pidfd，避免仅按可复用PID发信号。取消路径补齐已发布签名证据引用与明确原因。

该变更属于授权范围内的实现修复，未更改PFDAM数学构造、双签组合或TLS组策略。因源码摘要变化，旧矩阵与ZIP保留，新版重新执行完整验收、四档30次实验及交付复验；不将旧结果重标为新版本。
