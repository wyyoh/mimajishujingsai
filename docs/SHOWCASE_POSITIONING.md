# 面向新型电网的细粒度密态聚合与可信数据协同平台

读数源侧加密，负荷按需汇总。

我们的作品面向居民用电、园区协同和充电设施负荷统计，将团队自主PFDAM方案应用于数据源、聚合网关和统计端的协同流程。数据源加密原始读数，网关按业务授权选择并聚合密文，统计端恢复群体结果，再根据发布规则提供统计服务。业务人员可以查看区域负荷、比较不同群体的用电情况，并评估指定时段的园区负荷变化。

## 需求与功能

| 业务需求 | 平台功能 | 业务获得什么 |
|---|---|---|
| 不同主体协同统计用电情况 | 源侧加密、独立数据源身份、密态聚合 | 聚合网关处理密文，业务侧获得群体结果 |
| 按区域、类别和时段使用数据 | 主体授权、细粒度密文筛选、总和与平均值及报告数 | 统计任务与访问权限对应 |
| 控制精确统计结果的发布 | 固定分组、至少10个登记计量点、完整上报、共享发布历史 | 发布决定与业务任务、统计声明关联 |
| 核对数据处理的来源和过程 | 联合签名、SM3密文快照、回执与审计检查点 | 授权、回执、结果和时段之间可以核验 |
| 评估园区需求响应 | 三个参考日与一个事件日的16窗口密态计算 | 平均降负荷、相对变化、窗口能量差和有效覆盖 |

## 核心贡献

### 细粒度授权进入密文计算

团队自主PFDAM方案把业务授权与密文筛选、聚合联系起来。网关依据授权处理获准报告，统计端恢复群体统计。平台支持区域、数据类别和时段选择，以及总和、平均值和有效报告数三种统计需求。方案的前期研究与本次应用实现共同构成作品的技术基础，具体实现增量见[贡献说明](CONTRIBUTIONS.md)。

### 统计结果按规则发布

平台把结果计算和对外发布作为两个明确步骤。统计端核对完整分组、登记规模、上报情况和已有发布记录，统一管理页面、接口与导出中的结果输出。发布历史跨账户、任务与统计函数关联，每次发布形成签名决定。

### 密码证据贯穿业务对象

任务授权、聚合回执、统计结果和发布决定通过签名关联。SM3快照记录逐源密文批次，审计检查点关联网关处理过程。证据核验分别检查签名、可信密钥、指定任务及数据时段，园区指标还能从16份统计端签名输入精确复算。

### 混合密码融入实际业务链路

普通业务同时要求ECDSA与ML-DSA-65签名，并在上传和聚合转发链路检查X25519MLKEM768混合密钥建立。国密增强配置加入SM2签名、SM3摘要和TLS内SM4-GCM业务保护。平台同时提供密钥与证书登记、任务边界更新和撤销、管理审批、审计及受保护备份恢复。

## 场景展示

居民场景按授权区域查看群体负荷；园区场景联合多数据源，比较参考与事件时段的负荷；充电场景查看充电设施群体的高峰负荷。首页使用一条可点击的密文处理路径串起数据源、PFDAM网关和统计端，场景选择直接衔接已有任务配置。

园区需求响应是重点展示场景。相同计量点分别完成三个参考日和一个事件日的四时段计算，用三日均值形成参考负荷，展示四项业务指标及对比曲线。合成场景使用预设10%响应输入；UCI公开读数采用模拟分组进行历史负荷比较。结果页同时提供登记人数、发布状态和签名指标核验。

## 实证支撑

当前版本具有真实Chrome任务与本机功能检查记录。发布保护已有同条件成对实验：三个Source进程、四日期16窗口，120、300、900输入规模分别保留原始任务和构建版本。20对正式样本与6对预热共52次成功REAL任务，832个窗口完成独立集合与整数和核对，历史失败原件保留。[完整实验口径](PRIVACY_SCENARIO_ITERATION.md)

本机密码标准对齐检查逐次执行11项选定向量与边界，并关联9组适用应用控制；检查结果与代码版本、任务及实际记录对应。[本机标准对齐](LOCAL_STANDARD_PROFILE.md)

## 展示顺序

1. 在场景总览说明“读数源侧加密，负荷按需汇总”，沿角色路径介绍PFDAM的作用。
2. 选择业务场景，在协同任务中查看授权范围和群体统计；园区场景重点查看四日期评估。
3. 在密码能力页解释计算、发布、签名与通信各自承担的工作。
4. 在回执与审计页核验发布决定、结果声明、指定任务与时段证据。
5. 按评委关注点展开规模实验或本机自检，直接查看对应的真实记录。

现场实际运行、配置预览和历史回放分别以REAL、PREVIEW、REPLAY标识。当前演示环境为Windows与Ubuntu WSL，支持1至3个同机独立Source进程；数据来源和分组方式随场景显示。
