# 标准对齐执行对照

本页续接原始规划和分析，37项为工程观察，不是标准全条款或符合率。本机可执行研发范围完成；条件接口、正式全文、产品和真实部署依各项状态保留。详细证据摘要见同名JSON。

| 项目 | 负责阶段 | 实际结果与边界 |
|---|---|---|
| G01 · 算法/技术/产品分别论证 | S1 | 已区分算法向量、应用集成、独立实现、产品和部署证据；PFDAM参数安全仍待独立复核。 |
| N01 · 通信实体和重要数据传输保护 | S1 | 真实mTLS、对端指纹及混合组强制通过；跨物理机与独立TLS对端尚未验证。 |
| N02 · 边界控制和实际设备接入 | S6 | 已保留源身份和文件边界；网络边界设备及实际电网接入缺资源，不关闭部署项。 |
| D01 · 设备登录和远程管理 | S6 | 本机应用账户不等于设备/远程主机鉴别；回环HTTP边界保留，远程管理方案待实际部署。 |
| D02 · 资源策略与安全标记 | S2 | 策略/安全标记/主体范围及角色Landlock已实测；分类分级仍为模拟。 |
| D03 · 日志完整性 | S2 | 新增管理审计认证加密、HMAC-SM3链与独立锚；回滚/截断/修改/写入失败拒绝，损坏恢复永久标记缺口。 |
| D04 · 重要程序来源和完整性 | S2 | 受保护根批准程序指纹，变更及批准后变化拒绝；不覆盖OS/已安装依赖二进制/加载器来源。 |
| A01 · 应用身份鉴别 | S2 | 本地账户、会话修订撤销、失败限制和敏感操作重新鉴别；企业身份和岗位执行未验证。 |
| A02 · 策略和安全标记关联 | S1 | 授权、范围、函数、套件、数据/时段及安全标记的规范关联；必需签名AND。 |
| A03 · 传输机密性和完整性 | S1 | Source–GW/GW–UC真实混合TLS及增强SM4；浏览器回环HTTP不称全平台链路加密。 |
| A04 · 重要数据存储机密性 | S4 | 主动角色秘密和新私有任务JSON认证加密、私钥加密PKCS#8及角色解锁；公开结果/研究数据和历史私有实验另有范围。 |
| A05 · 存储完整性和原发接收证据 | S4 | V4独立UC声明认证规范结果内容与上下文；不独立证明解密、源完整性或测量事实。 |
| P01 · 参考第三级时所用产品模块要求 | S5 | 已界定软件适配层与库；无具体认证产品或模块证明，未确定部署等级。 |
| M01 · 制度和执行规程 | S2 | 管理、备份、撤销、审计故障及恢复操作可执行；实际组织制度和留痕由部署补充。 |
| M02 · 关键岗位职责与多人共管 | S2 | 管理者、审批者、审计者分离和一次性审批已测试；不是两名自然人的岗位执行证明。 |
| M03 · 实施和评估 | S7 | 当前源码回归与证据追溯已验证；正式密评、部署等级及最终参赛材料未完成。 |
| M04 · 密码安全应急 | S6 | 本地撤销、证书拒绝、登记/审计损坏、写入失败、材料恢复；根失陷与整机灾备为独立设计。 |
| K01 · 密钥产生、用途和使用约束 | S3 | 密钥用途/角色/版本/状态登记与生成、真实使用已核对；无密码设备或随机性检测认证。 |
| K02 · 秘密存储与公钥防替换 | S3 | 独立受保护根、加密私钥/JSON、双签登记及公钥替换/根替换/回滚拒绝；可信OS与首次引入前提保留。 |
| K03 · 更新和撤销 | S3 | 六把业务签名密钥真实轮换、撤销、TLS更新、任务边界等待、旧策略拒绝及登记中断恢复。 |
| K04 · 历史归档与信任维护 | S3 | V1/V2/V3原归档及V4轮换后历史数学核验；撤销时点缺独立可信时间不能判定历史可信签署。 |
| K05 · 按用途备份恢复和销毁 | S6 | 独立口令保护备份、当前信任约束恢复、逻辑删除和旧备份跳过；不证明物理清零或独立根丢失恢复。 |
| SM201 · SM2身份预处理和签验 | S1 | 正式选定例子核对身份预处理，三个用途域独立GmSSL双向签验、错身份/错消息拒绝。 |
| SM202 · 参数、编码和DER边界 | S1 | 推荐参数、公钥点与8类整数/DER负例已验证；对端接受尾随字节的差异单列；非完整算法认证。 |
| SM203 · 标准消息封装 | S5 | 无完整标准消息对端需求，未提供CMS/ASN.1标准消息适配；2026新版全文差异待补。 |
| SYM01 · GCM标准映射 | S1 | 补GB/T36624-2018 10.1及C.5，SM4例子和独立互通通过；17964不包括GCM，使用限额为应用策略。 |
| ID01 · 标准标识映射 | S1 | 已分内部名称、OID、接口整数、用途和编码；未实现标准设备接口，不臆造GCM标识；新版全文差异待补。 |
| MOD01 · 模块边界和敏感安全参数控制 | S1 | 已界定库/适配层/协调进程/角色和敏感参数，软件托管及文件边界实测；不等于完整模块等级证明。 |
| MOD02 · 运行前与条件自测试 | S5 | 应用启动SM3与SM4-GCM检查失败会停止；未提供37092全模块条件自测试或产品认证。 |
| SVS01 · 签验服务证书/备份/日志/时间 | S5 | 当前业务应用不是38629签验产品；所需服务对端、产品版本/证明、可信时间和完整接口未具备。 |
| SVS02 · 签验产品管理员鉴别与自检 | S5 | 本地管理账户/应用检查不冒充签验产品硬件初始鉴别或完整产品自测试。 |
| SVS03 · 标准签验服务接口 | S5 | 自定义业务API继续按应用接口使用，没有真实标准签验服务对端，不新建空壳适配。 |
| DOC01 · 文件内容与属性关联 | S4 | 规范JSON的属性、时段、来源、快照与结果/回执关联验证；不是完整电子文件指南测评。 |
| DOC02 · 结果声明及长期归档 | S4 | UC结果声明、历史公钥和登记保存，独立公开信任锚核验；长期可信时间/证书状态证据待补。 |
| TLCP01 · TLCP协议互通 | S5 | 没有真实TLCP接入需求或对端；TLS1.3内SM4继续显式区分，不降级SAB。 |
| SKF01 · 智能密码钥匙接口 | S5 | 智能密码钥匙/密码设备及相应接口全文资源未具备；没有设备实测或继承认证主张。 |
| OTP01 · 动态口令 | S5 | 本地随机固定访问口令不称动态口令；没有启用OTP方案或伪造重放测试。 |
