# 安全自检修订记录

本轮对应2026-10-18用户提出的自检功能完善要求。自检需要检查实际执行结果，不能把研究限制、设备认证和正式密评改成通过。

## 修订内容

- 未选中任务时，从当前运行环境的账户提交索引中自动选取可访问记录。检查所属账户、运行环境、私有实验和母子任务范围；不扫描所有研发归档。优先当前版本，历史任务明确标记。
- 检查国密标准向量和错误输入；核对软件托管、公私钥对应、证书身份和有效期、私有目录权限以及有效密钥登记。
- 使用实际授权判断函数测试允许请求、跨区、越级、无权统计、过期授权和降低保护要求。测试不会发起业务任务。
- 根据当前文件临时生成V5核验包，防止旧ZIP掩盖当前文件损坏；不覆盖历史导出包。
- 普通任务核对公开快照；四日期母任务在验证签名输入后，额外核对本机UC受保护的四个子任务工作副本，共16个时段。公开母归档仍不包含完整子快照，其他机器不能仅凭母归档完成这项检查。
- 逐个日期、逐条业务链路核对双方身份、实际混合组、业务请求、帧和流量记录；缺少某一天的端点不能由其他日期的记录抵消。
- 对内存副本执行密文改动、参与集合删除、审计修改/删除/重排，以及逐个必需签名的删除和改动测试。实际数据和原证据保持不变。
- 将公开发布投影与受保护根中的提交绑定，重新检查已发布任务的正式参与记录、完整固定分组、计量点去重、共享历史和发布标识。规则负例只使用明确标记的内存样例，不产生新的发布。
- 四日期业务指标、统计端结果签名、管理审计与程序批准分别核对。未发布任务的结果签名和结果快照标为不适用，不伪造成功记录。
- 页面展示实际检查摘要、证据任务、代码版本和下载记录；研究与标准/部署条件继续可见。无任务、旧版本、文件缺失和核验失败分别展示。

## 通过范围

已发布的普通任务有10项功能检查；四日期评估增加指标复算，共11项。全部适用检查通过后，显示“本机功能检查通过”。研究和标准对照不计入该通过数，整体状态仍为`HAS_OPEN_ITEMS`。

参数安全仍待独立论证；低熵候选策略和特定条件下类别可识别的限制不变。固定分组精确发布没有差分隐私保证。公钥签名认证声明来源和内容，不是公开可验证解密或源读数真实性证明。连接记录是可信宿主上的运行观察，不是独立签名的传输证明。

软件托管检查不替代HSM认证。当前传输不是TLCP，身份认证仍是经典ECDSA，PFDAM内核仍是经典密码。标准对照保留原版本和未启用条件，不宣称全标准符合。没有增加空壳设备接口、企业身份入口或伪认证来取得通过标签。

PFDAM数学文件、原生库、SAB签名AND、两段实际混合通信、角色隔离和历史对象规范保持。自检新增的JSON是研发报告格式，没有修改业务签名协议。
