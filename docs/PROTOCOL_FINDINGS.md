# PFDAM策略候选测试复核

原文：第五节B、D；DOI 10.1109/JIOT.2024.3356593。复现命令：`.venv/bin/python scripts/policy_audit.py`。结果：`artifacts/probes/policy_audit.json`，退出码0。

公共参数包含 S_j=g1^s_j、V=e(g1,g2)^v；令牌包含 omega_j=g2^(a_j/s_j)，其中 f(X)=v+product(X-H(Tag_t))。

持令牌的网关可计算 e(S_j,omega_j)=e(g1,g2)^a_j。对任意候选标签L，再计算所有 e(S_j,omega_j)^(H(L)^j) 的乘积，即 e(g1,g2)^f(H(L))。把该乘积与公共V比较，即可测试候选是否为授权多项式的根。公开任务nonce不改变这一等式。

在实际BLS12-381库上，1、2、3、5个不同标签的四组测试均恢复了六个候选中的真实授权集合。该复现使用真实群与配对；候选测试阶段只读取公开参数、已发出的令牌和候选标签。生成测试令牌时使用UC秘密不代表攻击阶段需要该秘密。

结论：本复现不能支持“对持令牌网关隐藏低熵授权集合”的主张，单标签与多标签均受影响。此结论不表示已恢复单户读数，也不表示ML-DSA或混合TLS被攻破。其他性质需要独立复核。

目前保留原文内核用于受限工程验证，不自行替换构造，不借外层A/B宣称修复该限制。按实施手册6.5节，最终保留限定范围或另行设计协议修正，由用户/导师决定。

参数另有待核对项：按V-A给出的alpha=4p'q'和h=-y^(2beta) mod N生成参数，实际h阶为2p'q'，与原文所称2alpha不同。当前生成器检查实际阶，恢复严格限定在普通整数除法正确的消息范围内。引用37全文未取得；ACM官方PDF地址返回HTTP403。现有摘要不足以完成参数安全复核。

## 多标签报告类别候选识别

当候选词表覆盖授权集合、授权多项式次数至少2且a1、a2非零时，上一测试恢复根集合后，攻击者知道非恒定系数a1、a2；仅a0混入未知v。对报告D_j=g1^(s_j k h^j)，可计算 X=e(D1,omega1)^(1/a1)=e(g1,g2)^(kh)，Y=e(D2,omega2)^(1/a2)=e(g1,g2)^(kh²)。对候选标签L测试 X^H(L)=Y 即可识别报告类别，无需UC或GW秘密、单户明文或私有映射。

真实BLS12-381测试对2/3/5个授权标签各产生6种候选类别报告，授权内外全部6种报告类别均被识别。命令 scripts/report_tag_audit.py，证据 artifacts/probes/report_tag_audit.json。需要上述条件，不能扩大为所有策略构造均受同一测试影响。

作品因此也不宣称对持令牌GW隐藏低熵报告类别。类别识别不等于读数恢复或物理设备身份识别；同一实体报告的不可链接性仍未完成独立审计。外层双签和混合TLS不修复该代数关系。
