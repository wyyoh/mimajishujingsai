# PFDAM参数、候选识别与作品定位复核

日期：2026-10-18。本文件为研发分析记录，不作为作品展示页。团队PFDAM数学、角色秘密划分和业务签名规范均未改变。

## 结论与定位

作品的已实现主线是原始读数在源侧加密、网关按授权处理密文、统计端核验并恢复群体结果。可展示的工程优势包括细粒度筛选、SUM/AVG/COUNT、联合签名、实际混合通信、逐源密文快照、可信密钥登记、发布控制和精确业务指标复算。

“加密读数”“隐藏策略”“隐藏报告类别”“保护已发布统计结果”是不同性质，应分别用证据判断。候选策略/类别测试成立，不等于已经恢复读数；也不能根据没有恢复读数就声称获得完整机密性证明。当前业务授权本身向网关提供区域、类别、函数和统计时段，见`services/governance.py`及V5签名政策。因此正常业务不以向执行网关隐藏这些授权元数据为必要条件。作品应围绕可验证的密态业务能力表述，不使用“授权策略不可识别”等已经撤回的主张。

## 参数检查取得的实质结果

本次直接核对本机3072位模数及对应受保护参数，保留命令、版本和布尔证据，不导出质因子、UC指数或其他私有参数。10项结构检查和真实边界值的独立集合/整数和核对通过，记录位于`artifacts/iterations/local-standards/parameter-review/2026-10-18T03-19-44.577Z.json`。

| 检查对象 | 实际核对 | 结论范围 |
|---|---|---|
| 参数结构 | N=pq，p、q、p′、q′的概率素性与尺寸，p=2p′cₚ+1、q=2q′c_q+1，所需互素关系 | 当前实例结构满足实现要求；概率素性检查不是证书化素性证明 |
| h及提升后的随机元 | 分别核对阶的幂关系，并对2、p′、q′逐个去因子检验 | 当前实例实际阶为2p′q′ |
| 解密消项 | α=4p′q′，t=2α=8p′q′；实际阶整除t，并核对提升随机元的t次幂 | 原文所称2α与当前实际阶有4倍差异，但本机消项条件成立 |
| 普通整数除法恢复 | 核对t·(900·10⁹)<N；超过恢复范围的请求被拒绝 | 对已声明业务数值范围，防回绕条件成立，当前实例比特长度余量2261位 |
| 实际群运算与恢复 | 自有样例含0、10⁹及未授权类别；独立计算预期集合和和，再与GW集合/UC结果比较 | 真实组件功能正确性通过；该探针不是完整SAB网络任务 |

消项后的聚合密文写作C=(1+MN)R mod N²，M为已授权读数之和，R为随机项。若Rᵗ=1，则Cᵗ=1+((tM) mod N)N mod N²。实现使用普通整数除法恢复，需要tM<N；本机检查的是这项确切条件，而非仅看模数位数。GW已在聚合时移除标签相关的掩码，最终M的上界为参与数×10⁹。

报告指数r采用1024位均匀随机采样。对当前公开记录的随机元阶位数，可给出取模分布偏差的保守上界：若阶d<2⁷⁶⁹，则相对模d均匀分布的总变差小于d/2¹⁰²⁴<2⁻²⁵⁵。这个分布界只回答采样接近均匀的问题，不是整个优化Paillier的安全级别。

## 候选识别的实际攻击面

令E=e(g₁,g₂)，公共参数Sⱼ=g₁ˢʲ、V=Eᵛ，令牌ωⱼ=g₂^(aⱼ/sⱼ)，f(X)=v+∏(X−H(Tagₜ))。网关可计算e(Sⱼ,ωⱼ)=Eᵃʲ，进而对候选L计算∏e(Sⱼ,ωⱼ)^(H(L)ʲ)=E^f(H(L))。与V比较即可测试候选成员。公开nonce改变标签哈希值，不消除这个等式。

既有真实BLS12-381记录覆盖1、2、3、5标签策略，候选覆盖的小集合中均恢复了授权项。进一步在授权根可恢复、多项式次数至少2且相关系数非零时，可利用D₁、D₂和令牌形成X=E^(kh)、Y=E^(kh²)，通过X^H(L)=Y识别报告类别。既有记录覆盖2、3、5标签策略，授权内外类别均被识别。

证据见`docs/PROTOCOL_FINDINGS.md`、`artifacts/probes/policy_audit.json`和`artifacts/probes/report_tag_audit.json`。本次没有覆盖或重标这些历史结果。既有攻击未恢复单个读数，不等于所有读数攻击均已排除。若未来要求策略或类别隐藏，应先形成新的安全模型与协议设计；加盐、公开nonce、加长参数、添加SM2签名或外层TLS均不能单独消除上述代数关系。

## 参数安全还需要什么

本次已把“结构和运算范围是否正确”落实为可执行检查。完整具体安全论证还要核对小子群选择及分解攻击、PDL/DPDL假设、配对与掩码组合、随机性和泄露模型，不能直接把3072位模数换算成整个方案的统一安全位数。

引用[37]的[ACSAC官方摘要](https://www.acsac.org/2021/program/final/s91.html)明确将单向性与语义安全关联到PDL/DPDL，并给出一组112位目标参数示例。该摘要没有提供足以把当前不同参数和PFDAM组合直接认定为同等安全的完整推导。ACM页面本次仍返回403，未声称取得全文。这一研究结论继续保存在技术记录中，不放入业务页脚，也不改写成“已证明”。
