# 威胁模型与解释边界

2026-10-17标准对齐迭代增加了软件秘密托管、双签可信登记、任务边界轮换撤销、独立账户审批和受保护管理审计。根独立于运行目录并保护最高登记状态，但仍信任操作系统账户、协调进程与首次引入的可信程序；不抵抗全机/同账户完全控制或连同独立根一起回滚。角色子进程仅解锁自己的材料，GW的原有秘密隔离保持。产品设备与正式部署认证仍未取得，详见STANDARDS_ITERATION.md及STANDARDS_OPERATIONS.md。

TA 负责可信初始化和本地注册，随后不常驻业务。Source 在本机模拟诚实节点，负责自己的读数及标签；GW 诚实但好奇，执行授权检查与密态选择，UC 可信地验证并恢复群体统计。保留原研究 GW/UC 不串谋的前提。宿主管理员、密钥泄漏、恶意 UC、恶意源伪造测量事实和物理传感器攻击均无完整防护证明。

对传输者提供 TLS 记录完整性、证书链和角色身份检查；对业务对象提供 required 签名和明确上下文绑定。签名数学有效、当前任务可受理、原生回执正确、恢复值与隔离真值一致分别验证，不能合并成“安全率”。

网关可见令牌、密文、窗口、源服务身份、计数及匹配结果。令牌允许低熵授权策略候选成员测试，单/多标签均已复现。候选覆盖授权集合、次数至少2且相关非恒定系数非零时，还可识别加密报告的候选类别，授权内外均已测试。作品不宣称这两类隐藏。类别识别不等价于读数恢复或物理设备识别，实体报告不可链接仍待独立审计。

PFDAM内核为经典配对与优化Paillier。ML-DSA-65增强外层授权、回执、V4结果声明及管理登记签名；混合密钥建立增强Source–GW/GW–UC会话秘密。X.509证书与TLS身份签名仍为ECDSA。作品不声称整体抗量子、NIST认证、商用密码产品认证或生产可部署。

Landlock 提供应用文件访问边界，在每个角色中实际尝试读取其他角色的秘密并确认拒绝。它不隔离整个宿主账号的管理权。本地 Web 服务绑定回环地址，V4.1增加本机原型账户、短时HttpOnly/SameSite会话和服务端主体权限；不是公网企业身份或多租户部署。120逻辑节点共享一个Source进程和一条L1连接，测得的是该模型的成本；执行锁保持计算串行。

公开导出包含群体结果、公开回执、连接元数据、性能和文件摘要；V4.1还包含模拟策略、密文快照/包含证明、参与报告摘要和GW签名审计检查点。不含token_bundle、源节点明文/映射、访问口令或私钥。回执签名保护其声明，不能独立证明UC发布明文对应其中密文；该关联依赖可信UC或私有oracle复验。离线验证器使用归档外信任来源，不信任归档自带公钥建立的新根。

公开验证器核对签名回执与结果的时段、计数、回执摘要及参数关联，并支持归档外预期任务。V1/V2/V3中的value_W等结果内容未获UC独立签名；V4新增UC结果声明，绑定完整规范结果及授权/回执/快照/数据/时段/密钥版本。文件摘要仍可被重算，运行状态、性能或连接日志未因此认证。V4认证UC声明来源和内容，不独立证明解密正确、源全集完整、读数真实或统计发布隐私。失败归档没有回执时不宣称回执认证成功，COMPLETED自述不能代替复验。

V5对已发布统计结果采用完整固定分组、至少10个登记计量点、正式参与记录、共享发布历史及统一出口。精确结果只在本轮规则允许的查询范围内发布；差分隐私不属于当前机制。依赖诚实Source、可信UC/宿主的条件和组合攻击分析分别保留，见PRIVACY_SCENARIO_ITERATION.md。2026-10-18的本机标准对齐范围和参数分析见LOCAL_STANDARD_PROFILE.md与PFDAM_SCOPE_DEEP_REVIEW.md，展示文字调整没有改变此威胁模型。

密钥管理当前支持双签保护的多epoch登记，TLS与对象签名用途分开。业务密钥和TLS身份可更新/撤销，管理操作等待在途任务退出再切换；被撤销的必需密钥阻止后续业务，没有自动回退。主环境为兼容旧入口保留epoch1，实际轮换/撤销在隔离环境验证；PFDAM参数和CA/登记根迁移保持独立。只读key_readiness核对对应关系与有效期，不等于HSM或产品证明。历史签名数学有效、当前撤销状态和可信签署时点分开报告，缺少独立时间不能推断撤销前可信签署。

V4.1密码敏捷分别约束对象签名、实际TLS组和附加业务加密。SM2采用显式用途ID，SM3快照/审计做域分离；SM4-GCM从当前完整TLS握手的exporter派生方向独立密钥，使用序列nonce、绑定链路/发送方/接收方/序号的AAD，接收端拒绝重放。每个任务连接生命周期有限且不复用会话。这是TLS内的应用保护，不是TLCP，也不是RFC8998的完整TLS配置。OpenSSL文档不承诺所有SM4实现路径恒定时间，本项目未做独立侧信道审计。

Merkle根证明签名声明的密文快照内容和包含关系，不证明Source未漏报或测量事实真实。授权签署在密文生成之前，绑定数据版本/范围/函数/套件/期限/nonce；快照根随后由Source生成、GW核对并在回执签名。aggregation_digest保护聚合密文和相关元数据，不是UC明文的公开正确性证明。审计检查点同样由GW声明，普通进程日志及后续事件没有因此获得独立认证。AVG由可信UC以总和/有效报告数表示，COUNT来自签名回执计数，不宣称新增同态除法或可公开验证的计数证明。
